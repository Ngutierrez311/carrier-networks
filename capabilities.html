Capability Statement

Carrier Networks LLC is an Albuquerque, New Mexico engineering firm. We build and defend network and security infrastructure, we run it as a managed service, and we apply artificial intelligence to both. We are built to work as a subcontractor to the primes serving the national laboratories, and to hold our own scope directly.

Core Competencies

Network Engineering

Network architecture, route and switch, SD-WAN, remote-access VPN, and best-practice assessment across Cisco, Juniper and HPE.

Perimeter and Edge Security

Firewall, web application firewall, load balancing, DNS security and reverse proxy with decryption, on Palo Alto Networks, Fortinet and F5.

Zero Trust and SASE

Identity-driven access architecture and secure access service edge design, migration and remediation.

Security Operations

SIEM and XDR, endpoint and network detection and response, continuous monitoring, and live SOC and NOC coverage.

Enterprise Linux and Automation

Red Hat Enterprise Linux, Ansible automation, containers and Kubernetes, and infrastructure delivered as code.

Log Platform Engineering

Graylog processing in front of OpenSearch on Kubernetes, sized to ingest rate and retention window rather than to a licence.

Artificial Intelligence in Operations

AI applied to configuration and change analysis, alert triage and enrichment, and automation, at a volume no team reads in full.

Security of Artificial Intelligence

Model and agent access control, prompt injection and tool-use abuse, data governance for training and retrieval, provider key handling and egress control, and model activity into the SIEM.

Cloud Infrastructure

VPC and VNET architecture, transit gateway and peering, security VPC design and high availability across AWS, Azure and Google Cloud.
