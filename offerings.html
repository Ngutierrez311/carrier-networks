Security Platform

The platform our managed SOC runs on, offered on its own. It is built to take everything an estate emits — firewall, endpoint, flow, cloud audit, application — rather than a sampled subset chosen to fit a licence.

  1. Collection Syslog, agents, flow records and cloud audit trails from network, endpoint, server and SaaS. Nothing is dropped at the edge to make a quota.
  2. Processing — Graylog Graylog nodes parse, normalise, enrich and route. The node count scales horizontally with volume, so ingest rate is a capacity decision rather than a ceiling.
  3. Search and retention — OpenSearch An OpenSearch cluster holds hot and warm tiers for interactive search, with policy-driven rollover into long-term archival for compliance retention.
  4. Orchestration — Kubernetes Kubernetes front-ends the OpenSearch cluster and runs every tier above it: ingress, scaling, rolling upgrade, failure replacement and tenant isolation.
  • What it delivers
    • Detection and alerting into the SOC workflow
    • AI-assisted triage across the full retained set
    • Full-fidelity search across retained data
    • Retention and archival evidence for audit
    • Dashboards and API access for your own teams
  • How it is run
    • Dedicated or multi-tenant
    • Hosted by us, or deployed into your cloud or data centre
    • Capacity sized to ingest rate and retention window
